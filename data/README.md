# Data

All data comes from U.S. Geological Survey data releases, which are public domain.

## raw/usgs_smackover_li/

Knierim, K.J., Blondes, M.S., Freeman, P.A., Masterson, A.L., McDevitt, B., Herzberg, A.S., Doolan, C., Chenault, J., Jubb, A.M., and Croke, M.R., 2024, *Lithium observations, machine-learning predictions, and mass estimates from the Smackover Formation brines in southern Arkansas*: U.S. Geological Survey data release, https://doi.org/10.5066/P9QPRYZN

Downloaded from https://www.sciencebase.gov/catalog/item/65395410d34ee4b6e05bbc08 (`sar_li.zip`, unzipped unchanged; `USGS_readme.md` is the release's readme).

## raw/usgs_pwgd_v3/

Blondes, M.S., and others, 2023, *U.S. Geological Survey National Produced Waters Geochemical Database v3.0*: U.S. Geological Survey data release, https://doi.org/10.5066/P9DSRCZJ

The 80 MB `USGS_NPWGDv3_excel.xlsx` is not stored in git. Download it from https://www.sciencebase.gov/catalog/item/64fa1e71d34ed30c2054ea11 into this folder before running `ml/prepare_data.py`.

## processed/

Generated by the scripts in `ml/`. Do not edit by hand.

| File | Made by | Contents |
|---|---|---|
| `wells.json` | `prepare_data.py` | 1,204 brine samples inside the USGS model area |
| `domain.geojson` | `prepare_data.py` | Outline of the USGS model area |
| `usgs_grid.json` | `prepare_data.py` | USGS lithium predictions for 2 km cells |
| `usgs_ml_input.csv` | USGS `1_SARLi_dataprep.py` | The 221-sample training table |
| `ml_metrics.json`, `ml_grid.json` | `train_lithium_model.py` | Our model's test results and grid predictions |
